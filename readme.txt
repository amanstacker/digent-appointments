A modern and flexible appointment booking plugin for WordPress that helps businesses manage appointments, schedules, services, and customer bookings with ease.

== Description ==

Digent Appointments is a powerful and user-friendly appointment booking plugin for WordPress designed for businesses, agencies, consultants, clinics, salons, and service providers.

The plugin allows you to create services, assign staff, configure schedules, and let customers book appointments directly from your website.

Whether you are running a small business or managing multiple staff members, Digent Appointments provides a flexible scheduling system to simplify your booking workflow.

= Features =

* Easy appointment booking system
* Staff and employee management
* Services and categories support
* Flexible schedules and working hours
* Booking calendar management
* Customer appointment form

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/digent-appointments` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Navigate to Digent Appointments from the WordPress admin menu.
4. Configure your services, staff, and schedules.
5. Add the booking shortcode to any page.
